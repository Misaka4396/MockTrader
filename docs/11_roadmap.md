## 二、四阶段路线图

### Phase 1（1-2 周）研究可信度 —— 进行中
    ✅ 样本外分割 + Walk-forward（tools/walkforward.mjs）
    ✅ 数据版本（DataAccess.dataFingerprint）
    ✅ 多源交叉校验（py/verify_sources.py）
    ✅ 冲击成本模型、真实路径前视审计
    验收：OOS 与 IS 衰减可量化；同数据同指纹；多源差异 <0.5%

### Phase 2（2-4 周）研究深度
    ⬜ alphalens 式因子流水线（分层收益/换手/IC 衰减）
    ⬜ 因子相关性矩阵 + 正交化、因子注册表（配置化）
    ⬜ cvxpy 组合优化（风险平价/板块约束）+ VaR/压力测试 + 回撤熔断
    验收：因子报告自动生成；组合有约束与风控指标

### Phase 3（4-8 周）实盘准备
    ⬜ 前向纸面验证记账（每天记录预测 → N 日后统计命中率/收益）
    ⬜ CTP 模拟盘；OMS + TWAP/VWAP；对账审计
    ⬜ 信号命中率看板 + 钉钉/企微告警 + 调度心跳/数据新鲜度监控
    验收：前向账本可回看；告警打通；执行与回测偏差可解释

### Phase 4（长期）规模化
    ⬜ 存储升级 Parquet/DuckDB；分钟线；容器化
    验收：数据查询秒级；分钟级回测；一键部署

## 三、一句话结论

先做「样本外验证 + 数据版本 + 多源校验」建立研究可信度（已完成），
再做「因子流水线 + 组合优化」提升研究深度，最后「前向记账 → CTP 模拟盘」打通实盘闭环，
每一步都有验收标准且构建在现有可复现核心之上。
