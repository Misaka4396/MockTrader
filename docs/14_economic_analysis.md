# 策略多学派经济学分析报告（docs/14）

> 分析对象：MockTrader 商品期货多空因子策略（5 因子：截面动量 / 流动性 / 成交量 / 价格偏度 / 展期收益率，
> 多 5 空 5、方向中性、月度调仓）。视角：奥地利学派 / 新古典经济学 / 行为经济学。

## 一、模拟结果（分析的事实基础）

| 指标 | 值 |
|---|---|
| 品种 / 交易日 / 调仓 | 45 / 782 / 32 次 |
| 交易 / 展期 | 450 笔 / 245 次 |
| 总成本（手续费+滑点 / 展期） | 18.0 万 / 23.8 万 |
| 期末权益 | 916.4 万（初始 1000 万） |
| 年化 / Sharpe / 最大回撤 / 胜率 | -2.78% / -0.447 / 13.14% / 40.85% |
| vs 纳指 15% 基准 | 超额 -17.78pp → 跑输 |
| 因子层：rollYield | 分层价差 +0.24%，IC(5d) +2.23%（唯一正 IC） |

关键事实：唯一有微弱正信号的是展期收益率（roll yield），其余因子在样本内接近零；总成本里展期滚动占大头。

## 二、奥地利学派视角（Mises / Hayek / Kirzner）

核心概念：主观价值、市场过程（非均衡）、价格=分散知识的聚合、企业家警觉、资本结构与时间偏好、
信用扩张→错误投资→繁荣→崩溃的商业周期。

### 优点

1. **尊重价格信号，直面「知识问题」**。策略完全不做基本面估值，只跟随价格（动量）与期限结构（展期收益率）。
   这正契合哈耶克「价格是分散知识的聚合器」——它诚实承认无法知道「真实价值」，只利用市场过程本身产生的信息，
   比「基本面价值投资」更奥地利。

2. **展期收益率 = 跨期资本结构与时间偏好的市场表达**。期货升贴水（contango/backwardation）按 Working/Kaldor
   仓储理论，是「持有成本 − 便利收益」，本质是时间维度上的稀缺性信号。把 roll yield 做成因子，是从「资本结构的时间维度」提取信息，
   正是奥地利学派最重视的资本结构与时间偏好。模拟中它也是唯一正 IC 的因子，验证了这一信号的「结构性」。

3. **无中央计划、自组织的截面中性**。策略不预设「哪个品种该涨」，用截面排序让市场过程自己选出强弱——一种「自发秩序」式的组合构建，
   而非计划者自上而下指定方向。

4. **不赌绝对方向、承认未来不可知**。多空中性 + 相对强弱，只押「相对」不押「绝对」，与哈耶克「未来本质不确定」一致。

### 不足

1. **动量是「追涨杀跌」，可能放大错误投资**。奥地利商业周期理论认为信用扩张制造「虚假繁荣」（malinvestment），
   价格上升≠真实财富增加。趋势跟踪会在泡沫期追多、加剧繁荣，在崩溃时被套；它无法区分「生产率驱动的真实趋势」
   与「货币扩张驱动的虚假趋势」。

2. **只有价格，没有「企业家判断」**。奥地利认为价格信号需要企业家去「解读」，纯量化把价格当唯一真理，
   放弃了米塞斯-科兹纳式的「企业家警觉」，无法识别结构性失衡（例如某品种的供给冲击）。

3. **合成数据没有真实的「市场过程」**。模拟数据是随机游走+均值回归，其中没有分散知识、没有企业家发现过程，
   所以负收益在奥地利框架下是「必然」——没有可发现的秩序，规则自然无效。这提醒：真实 alpha 来自对真实市场过程的理解，而非在噪音里找规律。

## 三、新古典经济学视角（理性预期 / EMH / 因子风险溢价 / 无套利）

### 优点

1. **完全站在因子文献上**。动量（Jegadeesh-Titman 1993）、流动性（Amihud 2002）、
   展期 carry（Koijen-Moskowitz-Moskowitz-Pedersen 2018《Carry》）、偏度（彩票偏好）都是顶级期刊验证过的因子。
   策略是教科书式的「因子组合」：截面 z + 多空中性，等价于 Fama-French 的 HML/SMB 构建法。

2. **绩效度量专业**。Sharpe / 回撤 / 基准超额，是新古典标准的绩效语言。

3. **组合优化（Phase 2）**。风险平价 / 板块约束，是新古典均值-方差框架的落地。

### 不足

1. **EMH 的当头棒喝**。若市场有效，这些公开因子要么是「风险补偿」（已定价），要么已被套利掉。
   结果 -2.78%、roll yield 仅有微弱正 IC(+2.23%)——恰恰说明「没有免费午餐」：公开因子在 2022-2024 样本里没有可提取的超额收益。

2. **因子是「数据挖掘」而非「风险溢价」**。策略没有给每个因子一个风险/行为的经济学解释（溢价为何存在？谁在付钱？），
   纯经验拟合。新古典的批评：没有经济学根基的因子大概率是过拟合。

3. **成本吃掉一切 + 套利限制**。450 笔交易 + 245 次展期，总成本约 41.8 万（其中展期 23.8 万），年化 -2.78%。
   这正是「套利限制」（limits to arbitrage）——交易成本与展期摩擦让微弱信号无利可图。

4. **理性预期 vs 合成数据**。合成数据按定义无因子结构，负结果是 EMH 的「正确零假设」。真实世界里这些因子
   也经历了「发表后衰减」（McLean-Pontiff 2016：异常收益在学术发表后平均衰减 30–50%）。

## 四、行为经济学视角（有限理性 / 反应不足与过度 / 损失厌恶 / 羊群 / 彩票偏好）

### 优点

1. **动量有扎实的行为基础**。Barberis-Shleifer-Vishny、Daniel-Hirshleifer-Subrahmanyam 的「反应不足+过度反应」模型
   为动量提供微观基础。策略系统性「买强卖弱」，正是对人性的反向利用——人类因处置效应过早卖赢家、死拿输家，策略反其道而行。

2. **量比/注意力因子**。Barber-Odean「注意力效应」：高成交量=高关注=可能过度反应，量比因子捕捉这一点。

3. **规则化克服情绪**。人类会恐慌抛售、追涨、过度交易；策略无情绪、纪律执行，规避了损失厌恶与羊群效应——这是量化相对主观交易的核心优势。

4. **新闻情绪（方案 A）**。把情绪直接量化成因子，是行为金融的典型落地。

### 不足

1. **行为 alpha 已被套利且拥挤**。这些偏差是公开的，被知晓后「聪明钱」套利使其衰减；同类策略拥挤会放大崩盘
   （如 2007 年 8 月「量化地震」、动量崩盘、carry 崩溃）。

2. **胜率 40.85% + 回撤 13.14% 是「行为上的毒药」**。损失厌恶（损失的心理痛苦≈2 倍收益）意味着：
   即便未来有正期望，多数交易亏损 + 连续回撤会让投资者在最低点赎回、放弃策略。策略在「人」的层面失败了——
   不是策略没 edge（这里确实没 edge），而是即便有，人也难坚持。

3. **模型自身的过度自信**。合成数据给出「因子看起来合理」的错觉，容易让人相信它在真实世界有效——
   这是过度自信、代表性启发作用于研究者自己。

4. **羊群/拥挤风险**。全市场都在跑同样的动量+carry，一旦反向会同步踩踏。

## 五、综合结论

三学派殊途同归，共同指向同一个核心判断：

1. **模拟跑输（-2.78%）是「正确的零结果」**——奥地利说「没有真实市场过程可发现」，新古典说「EMH 无免费午餐」，
   行为说「公开偏差已被套利」。三者在合成数据上的负收益是自洽的。

2. **优点各有侧重**：奥地利认可「尊重价格信号+截面中性」的设计哲学；新古典认可「因子构建的规范性」；
   行为认可「纪律执行克服人性」。

3. **不足殊途同归**：动量/展期的 edge 在真实世界存在但脆弱（拥挤、成本、发表后衰减、回撤难坚持），
   且「跑赢纳指 15%」是错误基准（机会成本参照，非同风险基准）。

4. **一句话**：这套系统的价值不在「跑赢纳指」，而在它是一个诚实的研究工具——用来研究市场过程（奥地利）、
   风险溢价与套利限制（新古典）、行为偏差（行为）。要真正盈利，需要真数据、真信号、以及对自己「不知道什么」的谦卑。
