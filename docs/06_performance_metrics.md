# S5 绩效与基准对比 (docs/06)

## 指标公式（口径注明）

设日收益 r_t = nav_t / nav_{t-1} - 1，n 为收益样本数：

| 指标 | 公式 |
|------|------|
| 年化收益率 | (nav_T / nav_0)^(252/n) - 1 |
| 波动率 | std(r) × √252 |
| Sharpe | (年化 - rf) / 波动率，rf=0（可配） |
| 最大回撤 | max(1 - nav_t / runningPeak_t) |
| 卡玛 Calmar | 年化 / 最大回撤 |
| 胜率 | 正收益日占比（基于日净值） |

## 基准（纳指长线收益率，单值常数）

- 默认 **15%**（约 10 年口径），可在 GUI 中修改。
- 基准非纳指逐日曲线；图表中的「基准复利虚线」= `(1+annual)^(t/252)`，仅代表这一常数。
- **超额收益 = 策略年化 - 基准年化**。

## 结论判定

```
excess >  +threshold (2pp) -> 跑赢
excess <  -threshold (2pp) -> 跑输
否则                        -> 接近
```

## 与绘图层解耦

PerformanceEngine 只输出指标 + 净值序列 + 基准数值 + 结论；图表（S7）仅消费这些数据，不内含指标计算。
